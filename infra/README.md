# Будущая инфраструктура Studium

Работающий cloud backend/deployment не реализованы и не нужны offline приложению.
Это место будущей инфраструктуры Studium; Bender — самостоятельный локальный
проект со stdio API, HTTP допускается как будущий adapter. Никаких deployment
commands, автоматической публикации или credentials этот candidate не добавляет.
