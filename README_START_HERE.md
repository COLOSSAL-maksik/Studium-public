## Главная архитектурная идея

Факты хранятся отдельно от выводов. Работы имеют историю попыток; вопросы и ответы — отдельную историю сообщений и связей с Topic/Skill/Assessment. AI в будущем создаёт только производные `AIInsight`, не меняя исходные факты автоматически.

## Первый вертикальный срез для разработки

1. Создать учебный период, дисциплину и группу.
2. Добавить студента.
3. Создать ДЗ.
4. Создать попытку сдачи с результатом `NEEDS_REVISION`.
5. Прикрепить фото.
6. Создать вторую попытку `ACCEPTED`.
7. Увидеть обе попытки в карточке студента и статус в матрице группы.
8. Добавить вручную вопрос из Telegram/Email и связать его с этим ДЗ и Topic.

После этого имеет смысл расширять UI, а серверную синхронизацию добавлять только после стабильного локального MVP.
