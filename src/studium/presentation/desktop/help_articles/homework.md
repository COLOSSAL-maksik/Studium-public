# Домашнее задание

Условия хранятся в «Библиотека» → «Домашнее задание». Нажмите «Создать материал», выберите дисциплину, заполните текст и при необходимости прикрепите общий файл или комплект условий.

Работу можно включить в рабочую программу либо выдать группе через «Выдать группе». Проверьте сроки выдачи и сдачи.

Для проверки откройте соответствующую ячейку журнала. Запишите дату, результат и комментарий; прикрепите работу студента. Переделка создаёт новую попытку. Прежняя сдача остаётся в истории.

Общие условия и файл студенческой попытки — разные вложения. Фактический статус выводится из записанных попыток.
