# Прогресс студента

Первый экран «Прогресса» — «Сводка»: выполнено/выдано, зачтено/выдано,
не выдано, отменено по категориям и исходным периодам, отдельно посещаемость.
Выполнено означает содержательную зарегистрированную сдачу, зачтено — явный
результат «Зачтено». Отменённые работы не увеличивают активный знаменатель.
Двойной щелчок категории открывает конкретные работы и их историю.

Ниже обязательные работы модулей всех периодов и долги. Требования не определены,
пока преподаватель явно не сохранит набор. «Оценено» не закрывает работу.
Для закрытия нужны зачёты всех обязательных работ. Долг прошлого семестра
остаётся у исходной работы и доступен после конца участия. Архивный контекст
восстанавливается отдельным подтверждаемым действием.

Другие вкладки показывают категории, аналитику, темы/навыки, свидетельства
и графики из тех же фактов. В «Графиках» можно двигать splitter и открыть таблицу
отдельно; размер сохраняется. Отсутствие сдачи/оценки не превращается в балл.
Посещаемость сохраняет прежний знаменатель.
