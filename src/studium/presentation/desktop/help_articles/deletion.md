# Удаление и сохранность истории

«Удалить» сначала показывает название записи и последствия. Удаление из активной работы сохраняет запись для исторических ссылок, попытки и файлы.

Группа, период, дисциплина и рабочая программа не владеют всеми материалами Библиотеки. Удаление учебного контекста не удаляет библиотечные условия, схемы, литературу или методические файлы.

Удаление задачи сохраняет прежние назначенные варианты. Снятие задачи с семинара удаляет только связь. Удаление работы из плана не стирает уже выданную фактическую работу.

Проверьте текст подтверждения перед действием. Массовая очистка внутреннего файлового каталога через интерфейс не выполняется.
