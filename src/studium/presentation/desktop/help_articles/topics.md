# Темы, подтемы и навыки

Откройте дисциплину → «Темы и навыки». Дерево показывает семестр и рабочую программу, модули, темы, подтемы и связанные навыки. Темы без привязки остаются в разделе «Темы вне модулей».

Выберите модуль и нажмите «Новая тема» либо выберите тему → «Добавить подтему». В форме задайте название, описание, родительскую тему, нужные модули и навыки. Создание навыка доступно прямо в выборе навыков.

«Изменить» позволяет исправить структуру. «Удалить» сохраняет исторические связи с работами и результатами. Циклическая родительская связь запрещена.

Вкладка «Навыки» служит для управления общим справочником дисциплины.
