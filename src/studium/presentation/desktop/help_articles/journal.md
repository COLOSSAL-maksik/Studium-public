# Работать с журналом

Откройте группу → «Журнал». Слева закреплены ФИО, справа — недели посещаемости и работы по модулям. Горизонтальная прокрутка сохраняет имена на экране.

Фильтр «Все / Посещаемость / ДЗ / РК» сокращает число столбцов. Короткие заголовки «ДЗ №1» и «РК №1» показывают назначение; полный текст доступен в подсказке.

Щелчок по работе открывает запись сдачи. Пустая плановая ячейка сначала выдаёт работу из программы; вымышленных попыток не создаёт. Enter открывает выбранную ячейку.

Знаки состояния: «—» — нет сдачи, «○» — предъявлено, «⚠» — доработка, «✓» — зачтено. Историю смотрите в карточке студента.
