# Задача с вариантами схем

Создайте задачу и выберите семейство вариантов. Общая карточка хранит формулировку, назначение, темы, навыки и теги.

Сохраните семейство, затем откройте «Варианты схем» → «Добавить вариант». Укажите код варианта, параметры, правильный ответ и прикрепите схему. Каждый вариант получает собственные файлы, а классификацию наследует от семейства.

В Банке задач выделите семейство и переключайте варианты в предпросмотре. Для редактирования откройте вариант из карточки семейства.

«Удалить вариант» сохраняет старые назначения и историю. Не заменяйте файл уже назначенной схемы новой задачей без проверки её смысла.
