# Начало работы

Studium хранит учебные записи локально и работает без подключения к интернету.

1. На главной создайте учебный период, дисциплину и группу.
2. Для группы выберите дисциплину и рабочую программу. Этот контекст связывает журнал с планом семестра.
3. Добавьте студентов во вкладке «Студенты» группы.
4. Ведите посещаемость и сдачи через «Журнал».

«Работа» открывает группы, «Дисциплины» — программы и содержание, «Библиотека» — общие материалы. Кнопка «Назад» возвращает к предыдущему экрану. Период выбирается справа вверху.

Начните с [периодов](help:periods) и [рабочей программы](help:programs).
