# Отчёты и экспорт

Откройте **Отчёты** в боковом меню. Учебный период выбирается общей кнопкой
в верхней части Studium. В поле **Дисциплина / группа** выберите нужный
учебный контекст.

Доступны три вида: **По студенту**, **По группе**, **По работе / РК**.
Для первого выберите студента, для третьего — конкретную работу. Переключатель
**Включить архивный контекст и завершивших участие** позволяет просмотреть
сохранённую историю в выбранном периоде.

Нажмите **Сформировать**. Заголовок показывает контекст и дату формирования.
Вкладки содержат работы, фактические статусы, попытки, оценки, результаты частей
и применимые разделы посещаемости или фактов по темам и навыкам.
«Последняя оценка» — последняя записанная Grade; соседняя колонка указывает
номер её попытки. Текущий статус и балл следуют обычным правилам истории
попыток. Отсутствие оценки показано прочерком, число 0 остаётся нулём.

**Сохранить CSV…** сохраняет таблицу выбранной вкладки. Файл имеет постоянный
порядок колонок, UTF-8 и корректно сохраняет кавычки и многострочный текст.
Дата в CSV записывается с часовым поясом UTC. Preview и PDF показывают время
в локальном часовом поясе компьютера.
Числовые оценки и максимальные баллы в CSV сохраняются без экранного округления.
Текст, который табличный редактор может принять за формулу, получает начальный
апостроф. Обычный текст и текстовые оценки сохраняют исходные значения.

**Сохранить PDF…** сохраняет весь отчёт, включая все вкладки, в формате A4
с альбомной ориентацией. Длинные таблицы переносятся на следующие страницы;
внизу указан номер страницы. Пустые разделы отмечены «Нет данных».
PDF использует тёмный текст для печати независимо от темы оформления Studium.

В диалоге сохранения самостоятельно выберите папку и имя файла. Отмена
ничего не сохраняет. При смене вида, студента, работы или периода preview
сбрасывается: сначала сформируйте новый отчёт.

Экспортированные файлы находятся **вне managed хранилища Studium**: они
не становятся вложениями, не регистрируются в базе и не входят автоматически
в резервную копию приложения. Папку самого хранилища и папки внутри любого
Git-репозитория выбрать для экспорта нельзя, в том числе через ссылки на них.
Отчёты создаются локально и не отправляются по сети. В файлах могут быть ФИО
и учебные факты; выбирайте подходящее место хранения.

Создание отчёта не меняет работы, попытки, оценки и посещаемость. Отчёты
показывают существующие факты без рейтингов, прогнозов и общей оценки студента.

См. также [Учебные периоды](help:periods), [История попыток](help:attempts),
[Посещаемость](help:attendance), [Как хранятся файлы](help:files).
