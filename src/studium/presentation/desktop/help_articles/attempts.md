# История попыток: сдачи, проверки и возврат

Карточка студента → Прогресс → Сводка/Работы → «+ Зарегистрировать сдачу».
Выберите исходную работу и период, фактическую дату получения, смещение UTC
для срока проверки, комментарий и несколько файлов. До «Сохранить» файлы
только в списке; их можно убрать, отмена не создаёт попытку. Каждая новая сдача
создаёт следующую реальную Attempt. Дата получения и дата внесения раздельны.

История работы → «Проверить»: выберите результат, дату проверки, при необходимости
балл/тип оценки и проверенные файлы преподавателя. Повторная проверка сохраняет
новую проверку той же сдачи, не прибавляет Attempt. После «На доработку» завершение
требует «Зачтено»; «Оценено» само не означает зачёт. Ожидание/доработка без балла,
не ноль. Минимум — нижняя граница начисления. Дробный ввод включается в Настройках.
После изменения правила старой сдачи явно выбирайте правило сдачи или текущее.

Оригиналы студента и файлы преподавателя находятся на отдельных вкладках.
«Редактировать рабочую копию» открывает копию, сохранённые bytes не меняются.
После редактирования прикрепите файл в новой проверке. «Возврат» фиксирует
отдельную фактическую дату. «Исторические попытки» показывает прежние записи.

Главная → «Очередь проверки»: ДЗ/РК всех групп по фактическому поступлению.
По умолчанию 7 календарных дней, последние 24 часа — срок близко; на равенстве
ещё не просрочено. Настройки сохраняются. Проверенные сдачи доступны в истории;
новая пересдача снова появляется в очереди.
