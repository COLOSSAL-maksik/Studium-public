# Как хранятся файлы

При добавлении файла Studium сохраняет собственную копию во внутреннем каталоге данных. После успешного импорта исходник можно переместить или удалить: вложение открывается по сохранённому внутреннему пути.

Нажмите большую область добавления или перетащите несколько файлов. Дождитесь завершения импорта. В списке видны исходное имя, размер и состояние. Изображения и PDF имеют встроенный просмотр; «Открыть» использует программу Windows.

DOC/DOCX сохраняются как файлы, их встроенный текстовый просмотр не предусмотрен. Для DOC может понадобиться совместимая программа Windows.

Если внутренний файл пропал, Studium сообщает об этом. Не редактируйте вручную каталог хранилища.
