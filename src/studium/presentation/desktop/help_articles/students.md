# Студенты и состав группы

В группе откройте «Студенты» → «Добавить студента». Можно создать нового студента или выбрать уже существующего.

Поиск фильтрует состав. Двойной щелчок по студенту открывает его карточку. В карточке доступны работы, посещаемость, вопросы и прогресс.

Вывод из учебного контекста завершает принадлежность, сохраняя предыдущие попытки. «Показать завершивших» позволяет видеть исторический состав. Удаление студента убирает его из активной работы с сохранением истории.

Не создавайте дубль студента для повторной сдачи: [новая попытка](help:attempts) добавляется к прежней работе.
