# План семинара и задачи

Создайте или откройте материал в «Библиотека» → «Семинары». Вкладки разделяют «План», «Задачи», «Файлы», «Темы» и «Заметки».

В «Задачи» выберите задачи из банка. Поиск и фильтры помогают подобрать несколько задач; выбор сохраняется при смене фильтра. Удаление строки здесь снимает связь с семинаром, сохраняя саму задачу в Банке.

«Создать задачу» открывает форму новой задачи с дисциплиной семинара и назначением «Семинар». После сохранения задача появляется в Банке и связывается с семинаром. Для нового семинара завершите сохранение основной карточки.

Прикрепите план и дополнительные материалы во вкладке «Файлы».
