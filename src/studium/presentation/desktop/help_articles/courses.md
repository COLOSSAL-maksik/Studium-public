# Создать дисциплину

Откройте «Дисциплины» и нажмите «Добавить дисциплину». Укажите название, сокращение и описание, затем сохраните.

Откройте дисциплину, чтобы работать с её программами, темами, навыками и материалами. Одну дисциплину можно использовать в нескольких периодах и группах.

Для исправления реквизитов используйте «Изменить». «Удалить» убирает дисциплину из активной работы после подтверждения. Её программы, библиотечные материалы и история сохранят связь с удалённой дисциплиной. Создание одноимённой дисциплины не переносит эти связи автоматически.
