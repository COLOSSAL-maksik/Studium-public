# Добавить группу

Откройте «Работа» → «Добавить группу». Заполните номер и реквизиты. Откройте группу и во вкладке «Настройки группы» добавьте дисциплину и рабочую программу.

Верхний список внутри группы переключает учебный контекст. Его период, дисциплина и программа определяют журнал и доступные работы.

«Настройки группы» содержит изменение реквизитов и удаление группы. Перед удалением появится подтверждение: учебная история и файлы сохраняются, материалы Библиотеки не удаляются. Удаление группы не удаляет студента из других групп.

Добавление учащихся описано в [статье о студентах](help:students).
