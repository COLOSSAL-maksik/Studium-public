# Рубежный контроль из банка

В «Библиотека» → «Рубежный контроль» доступны сохранённые комплекты. Работы РК также задаются как условия и включаются в программу.

Группа → Работы → Контрольные → выбранная работа → «Задачи и варианты» открывает
существующую генерацию Studium именно для этой работы. Выберите назначение задач,
критерии и количество; просмотрите набор, сохраните и назначьте студентам.
Плановую работу сначала явно выдайте через «План семестра».

Семейства задач дают варианты схем. Общая классификация наследуется от семейства. Назначение фиксирует выбранные условия; удаление исходной задачи из активного банка не стирает прежние назначения.

Регистрация фактической сдачи с файлами создаёт новую попытку. Проверка относится
к той же сдаче, сохраняет своё правило, результат и файлы преподавателя; номер
Attempt не увеличивается. Для результатов отдельных задач откройте историю
сдачи → «Результаты задач сдачи». Новая пересдача создаёт следующую попытку.
«Зачтено» задаётся явно, возврат преподавательского варианта фиксируется отдельно.
