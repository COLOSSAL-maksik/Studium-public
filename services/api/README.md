# Будущий API Studium

Здесь нет действующего сервера. Studium остаётся полезным локально без cloud.
Будущий Bender integration client относится к Studium и использует JSON-RPC 2.0
over stdio к отдельному Bender процессу. Сам Bender API реализует Jules в своём
repo. API/client/HTTP/server сейчас не реализуются.
