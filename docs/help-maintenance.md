# Встроенная справка Studium

> Документ относится к Studium как независимому локальному приложению.
> Bender — отдельный проект; будущая интеграция использует локальный JSON-RPC
> 2.0 over stdio. Прямые импорты Bender, API/client, облачный сервер и новые
> возможности этим переносом не реализованы. Описания прежних фаз сохраняют
> технические требования; их проверки и acceptance не подтверждены этим текстом.

Индекс: `src/studium/presentation/desktop/help_articles/index.json`. Каждая статья —
отдельный Markdown resource с устойчивым ID. `help_center.py` читает их через
`importlib.resources`, выполняет локальный поиск по названию, разделу и тексту.
Загрузка не требует сети, web engine или новой dependency. Ресурсы включены
в setuptools package data и `Studium.spec`.

`MainWindow.open_help(article_id)` и `help_center.open_help(owner, article_id)`
открывают статью в том же MainWindow. Неизвестный ID показывает объяснение и
оставляет навигацию доступной. Ссылки `help:files` переключают статьи локально.

Definition of Done: если пользовательский workflow изменился, обновить только
затронутые статьи и связанные записи индекса. Если behavior не менялся, справку
не переписывать. Использовать названия фактических кнопок и полей, описывать
результат и сохранность истории; не выставлять будущие функции как доступные.
После изменения проверять открытие статьи, локальный поиск и наличие ресурса
в portable package. Текст хранить отдельно от presentation-кода.
